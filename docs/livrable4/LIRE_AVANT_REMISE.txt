ANNEXE CODE
Code_source/ contient les sources C, en-têtes, pilotes, bibliothèques et licences,
interface Python, tests, scripts de compilation et configuration PlatformIO.
Les .bak, .git, .pio, fichiers de travail et anciens binaires dist sont exclus.
Le code actif correspond au commit 6bc3343 ; les documents locaux complètent ce code.
Consulter Code_source/LANCEMENT.md et docs/INSTALLATION_VIRTUALBOX.md pour l'installation.
Compiler depuis Code_source/ avec : pio run -e nucleo_l476rg
Les dépendances STM32 doivent être installées par PlatformIO lors de la première compilation.

CONSIGNES ET POINTS À VALIDER
La transcription du tableau est en annexe B ; les mots incertains sont signalés.
La ligne GPS paraît demander : « Si GPS KO → dupliquer une mesure OK ».
Le code livré utilise 0,0 (DEMO) après 15 s avec GPS_DEMO=1 ; il ne duplique pas
une ancienne mesure valide. L'écart est explicite et doit être validé avec l'enseignant.
La note finale sur un scénario d'usage est partiellement lisible ; l'annexe C
propose un scénario réel avec variation de luminosité sans ajout de potentiomètre.
Les vidéos, photos de secours et relecture physique .LOG restent à joindre par le groupe.
Aucune vidéo inexistante n'est annoncée comme fournie.

RÉSULTATS ET ESTIMATIONS
Compilation et tests C/Python relancés avec succès pour cette remise documentaire.
L'autonomie de stockage de 87 à 107 jours est une estimation conditionnelle de
limite du répertoire pour de très petits fichiers, pas le remplissage garanti des 8 Go.
Les données GPS DEMO sont identifiées ; --demo simule au contraire tout le tableau de bord.
La précision des capteurs et l'autonomie batterie ne sont pas certifiées.
